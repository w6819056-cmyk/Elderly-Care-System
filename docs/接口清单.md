# 接口清单（一期）

- 统一响应：`{ "code": 0, "message": "success", "data": ... }`，`code = 0` 为成功。
- 业务异常映射：400 参数/业务校验失败、401 未登录、403 无权限、404 不存在、409 状态冲突。
- 鉴权：`Authorization: Bearer <token>`，token 有效期 72 小时。
- 时间格式：`yyyy-MM-dd HH:mm:ss`，同时兼容 ISO-8601。
- 在线文档：启动后访问 `/swagger-ui.html`。

## 安全监护（SA-01~SA-10）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/alerts/sos` | 仅老人本人 | 一键紧急呼叫，生成红色告警并推送家属（短信+站内）与平台 |
| POST | `/api/alerts/elders/{elderId}/trigger` | 老人本人/家属/管理员 | 设备或模拟事件接入：FALL / GEOFENCE / INACTIVITY / VITAL_ABNORMAL |
| GET | `/api/alerts/elders/{elderId}?status=&limit=` | 老人本人/已绑定家属/管理员 | 某老人的告警列表 |
| GET | `/api/alerts?status=&level=&limit=` | 管理员/服务方 | 全平台告警工作台 |
| POST | `/api/alerts/{alertId}/handle` | 家属/服务方/管理员 | 处置：`action` = ACK / FOLLOW / ARCHIVE，按状态机校验 |
| GET | `/api/alerts/{alertId}/logs` | 同处置权限 | 处置流水（触发、确认、回访、归档全程记录） |

告警分级规则：`SOS`、`FALL` → 红（紧急）；`GEOFENCE`、`INACTIVITY`、`VITAL_ABNORMAL` → 黄（关注）；其余 → 蓝（提示）。
红色即时多渠道触达家属与平台；黄色推家属站内消息；蓝色仅入库（对应 MSG-03）。

## 服务调度（SV-01~SV-15）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/public/services?category=` | 公开 | 服务商城，仅返回审核通过且在售项目 |
| POST | `/api/orders?elderId=` | 老人本人/家属 | 下单；家属代下单必须传 `elderId` 且已绑定 |
| POST | `/api/orders/{orderId}/pay` | 订单所属老人/家属 | 模拟支付，成功后自动派单并生成工单 |
| POST | `/api/orders/{orderId}/cancel` | 订单所属老人/家属 | 待支付→已取消；待接单→已退款 |
| POST | `/api/orders/{orderId}/review` | 订单所属老人/家属 | 评价 1-5 分，仅一次，完成后订单结束 |
| GET | `/api/orders/{orderId}` | 订单相关方/机构/管理员 | 订单详情 |
| GET | `/api/my/orders?status=` | 老人/家属 | 我的订单（家属为已绑定老人订单） |
| GET | `/api/provider/orders?status=` | 服务方 | 本机构工单列表 |
| GET | `/api/provider/orders/{orderId}/work-order` | 服务方 | 工单信息与操作流水 |
| POST | `/api/provider/work-orders/{workOrderId}/accept` | 服务方 | 接单并指派护理员，订单进入服务中 |
| POST | `/api/provider/work-orders/{workOrderId}/checkin?action=START\|END` | 服务方 | 上门打卡，记录时间与经纬度；END 后订单进入待评价并生成结算流水 |
| GET | `/api/admin/orders?status=&limit=` | 管理员 | 全量订单监控 |
| POST | `/api/admin/orders/{orderId}/dispatch` | 管理员 | 人工改派（异常订单干预） |
| POST | `/api/admin/orders/{orderId}/refund` | 管理员 | 全额退款 |

订单状态机：

```
PENDING_PAY ──pay──▶ PENDING_ACCEPT ──accept──▶ IN_SERVICE ──checkin END──▶ PENDING_REVIEW ──review──▶ COMPLETED
     │                     │                        │
     └──cancel──▶ CANCELLED └──cancel/refund──▶ REFUNDED ◀──refund──┘
```

派单规则（SV-11）：
1. 服务项目已归属服务商，且该服务商审核通过、服务区域匹配 → 直接派给该服务商；
2. 否则在同区域合规服务商中选「在办工单数最少、评分最高」者；
3. 无可用服务商 → `providerId` 置空，进入平台人工派单队列。
