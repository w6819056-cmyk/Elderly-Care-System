# 企业与门店公开首页

## 访问入口

- 企业品牌首页：`/brand`。
- 门店用户首页：`/stores/:storeNo`。
- 咨询、参观预约：`/stores/:storeNo/visit`。
- 总部内容维护：`/hq/site`。
- 门店内容维护：`/store/site`。

用户首页不展示企业总部或员工后台入口。员工后台继续使用 `/store-admin/:storeNo`。

## 内容与发布

支持标题、副标题、企业或门店介绍、服务理念、公开地址、公开电话、到访说明、首图和最多六张环境照片。公开联系方式独立维护，不自动读取内部员工信息。

总部品牌内容保存草稿后直接发布。门店内容保存、提交总部审核后发布；审核期间修改草稿不会改变已送审版本。审核携带送审内容的摘要，送审版本改变时旧审核请求返回 409。公开接口仅返回已发布版本，驳回不撤下之前已发布内容。

权限为 `core.site.view`、`core.site.manage`、`core.site.review`。审核还要求总部身份及相应门店数据范围。受保护的企业所有者权限组自动加入这些权限；普通角色需总部按职责分配。

## 数据与图片

V8 迁移新增 `site_public_content`，按品牌或门店保存草稿、送审、发布快照。未发布介绍、电话和照片会明确提示尚未发布；系统生成图片标注为 AI 示意，不作为机构实拍。

上传支持单张不超过 2MB 的 JPG/PNG，服务端检查真实格式及尺寸，压缩并重新编码后存入内容 JSON。当前图片随数据库备份；后续可迁移至客户自身对象存储。数据库不包含平台端业务数据同步。

## 开发接口

公开 GET：`/api/public/site/brand`、`/api/public/site/stores`、`/api/public/site/stores/{no}`。

认证 GET/PUT：`/api/tenant/v1/site-content/{target}`，target 是 `brand` 或门店 publicId。POST 同路径追加 `/publish`、`/submit`、`/approve`、`/reject`；审核体包含 `reviewToken` 与可选 `note`。门店员工通过 GET `/api/tenant/v1/site-content-store` 获取自身门店目标。

付费服务目录、服务价格及业务预约由后续业务模块接入；当前预约仅为免费咨询或到店参观意向。
