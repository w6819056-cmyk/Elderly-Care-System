# 门店门户与入职申请

## 页面
/stores/:storeNo 为公开门店首页，/login 与 /register 为其子路径。门店管理提供打开及复制入口。总部 /hq/staff-applications 审核申请。

## 接口
- GET /api/public/store-portals/{no}：仅营业门店展示名称、编号与企业名称。
- POST .../{no}/login：account/password；签发令牌前验证 STORE 类型与所属门店。
- POST .../{no}/applications：username/password/displayName/phone/email。保存密码哈希，返回申请编号，不能直接登录。
- GET /api/tenant/v1/hq/staff-applications：iam.staff.view，门店数据范围裁剪。
- POST .../staff-applications/{id}/review：iam.staff.manage，decision=APPROVE/REJECT，roleCodes、note；行锁下事务审核，复用 IAM 门店范围/角色域/所有者保护，创建失败回滚并保留待处理状态。完成后移除申请密码哈希。

## 存储与运维
V5 独立迁移新增 iam_staff_application，不修改旧迁移。公开申请/登录当前按服务进程内 IP 限制 10 分钟 10 次，多实例部署需在网关配置统一限流。采用连接 IP，不直接信任调用方 X-Forwarded-For。申请资料保留于客户自己的企业库，禁止明文密码或哈希出现在列表/日志中。

## 验证与边界
集成测试覆盖申请不开户、审批开户、重复审批拒绝、正确门店登录、错误门店登录拒绝及审批后密码哈希清除。公开首页当前展示基本资料与图片，商业服务、支付、品牌内容编辑和申请自助查询不在本轮。
