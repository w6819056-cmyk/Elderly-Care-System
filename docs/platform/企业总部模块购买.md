# 企业总部模块购买

## 购买与代码版本的边界

企业总部购买的是模块商品或套餐授权，不在下单时选择 `.caremod` 代码包版本。订单只记录模块/套餐、授权期限、名额、价格和订单状态；它不会因为平台后来发布新版本而自动生成新的订单或覆盖企业当前安装版本。

因此，企业购买“会员模块”后获得的是会员模块的有效授权。具体运行哪个代码版本，由企业总部进入安装中心后按当前底座兼容性选择：系统默认推荐最新已发布且兼容的版本，也允许总部在版本详情中选择仍受支持的旧版本。

安装计划才绑定具体的 `moduleCode + version + sha256`。确认安装或升级前，企业端会重新校验包签名、摘要、底座版本、依赖和授权；平台发布新版本不会静默修改企业环境，升级必须由企业总部明确确认。

同一模块的续费、追加期限或重新购买只调整授权有效期，不把旧安装版本和新版本拼成多个业务模块。升级失败时保留原已运行版本并进入恢复处理状态，不自动删除模块数据。

## 使用入口

企业总部 `/hq/shop`：单模块、套餐组合、购买记录。总部具有 core.module.view 才能访问，创建订单、模拟支付、取消订单、同步授权另需 core.module.purchase。企业最高管理员会从现有权限解析器获得新激活的核心权限；其他角色由总部显式分配。门店账号始终拒绝。

商品来自平台启用的售卖卡片。卡片图片、名称、介绍、价格和授权期限读取销售商品；套餐全模块均永久拥有时不展示。永久拥有的单模块不再重复出售。卡片只选商品，不允许企业前端提交价格、门店额度或任意企业编号。

## 流程

1. 选择模块/套餐，输入可选优惠券码，获取企业实际报价。
2. 平台根据已验证的实例确定企业，检查销售状态、已有授权、正式依赖、优惠券，计算最终金额及预计到期时间。
3. 创建订单使用稳定幂等键；请求结果不明时重试同一次操作，或查看购买记录。后端请求签名每次使用新 nonce。
4. 本地演示可模拟支付；生产默认为关闭，真实微信/支付宝/银联支付尚未接入。创建订单后展示最终订单金额，再确认支付。
5. 支付履约后同步许可证，进入模块安装，由总部确认安装；随后在模块授权页启用并分配门店与员工权限。购买不等于已安装。
6. 待支付订单可以取消，取消后释放预留优惠券。已支付订单不得通过此入口取消。

## 接口与身份边界

企业端接口前缀 `/api/tenant/v1/hq/shop`：
- GET /configuration：实例是否配置、当前员工购买权限、可选宣传图片基地址；不返回实例私钥。
- GET /catalog：可购买售卖卡片、模拟支付是否可用。
- POST /quote：productId/planId 二选一，couponCode 可选。
- POST /orders：同报价字段加 idempotencyKey（8至80位字母数字下划线或连字符）。
- GET /orders、GET /orders/{id}：本企业购买记录与订单详情。
- POST /orders/{id}/pay-simulated：仅平台显式开启本地演示开关时可用。
- POST /orders/{id}/cancel：仅待支付订单。
- POST /sync-license：使用现有签名许可证同步协调器，验证平台签名后落本地快照。

企业后端通过 `PlatformLicenseClient.commerce` 签名调用 `/api/platform/v1/instances/{instanceId}/commerce` 对应路径；请求体摘要、时间戳、nonce、实例ID全部校验。订单企业身份从 VerifiedInstance 派生，不接受浏览器指定企业。订单详情、取消、支付都做企业归属检查。签名端点不持有平台管理员JWT。

平台订单 `created_by` 对实例下单为空，`source_instance_id` 保存来源实例；审计主体为 INSTANCE:<id>。不冒充平台管理员账号或把企业员工ID塞进平台管理员字段。企业侧另记实际操作员工审计。只交换软件商品、订单和授权信息，不上传客户/老人数据。

## 配置与迁移

- 平台 V9：订单来源实例、可空平台管理员创建人。
- 企业 V12：购买模块与套餐权限定义。
- 启用 app.license.enabled，配置平台地址、orgNo、实例ID、指纹、实例私钥和可信平台签名公钥。已有激活身份禁止擅自更换或生成新的密钥。
- 图片为 HTTPS 时直接展示；`/images/` 相对地址可通过企业后端 app.commerce.image-base-url 指向平台宣传资源域名。为空时使用企业站点同路径图片；内置会员封面有本地后备。
- platform.commerce.mock-payment-enabled 默认 false，本地演示明确设为 true。不能将演示开关当作真实收款渠道。
- 预览实例配置和私钥保存在仓库外的本机私有目录；重启使用这份配置，不可使用 dev profile 重建数据库。

## 验证

组件测试覆盖未激活提示、只读员工禁止购买、企业报价、幂等下单参数与不提交企业编号。
签名集成测试覆盖商品读取、企业报价、幂等下单、实例审计来源、模拟履约、跨企业订单拦截、无签名及篡改请求拒绝。
企业服务测试覆盖总部只读权限、门店即使持有购买权限仍被拒绝，以及平台响应透传。

当前购买记录展示最近100单。真实第三方支付、订单超时自动取消、退款后返券等仍是独立后续工作。
