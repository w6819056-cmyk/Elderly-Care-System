# 平台控制面接口清单

基础前缀：`/api/platform/v1`。成功响应统一为 `ApiResponse`：`code=OK`、`message`、`data`、`traceId`、`timestamp`。金额序列化为字符串，时间使用 UTC ISO-8601。

## 认证与健康

| 方法 | 路径 | 权限 | 请求 | 成功 |
|---|---|---|---|---|
| GET | `/health` | 无 | 无 | 200 |
| POST | `/auth/login` | 无 | `username,password` | 200 |
| GET | `/auth/me` | 平台登录 | 无 | 200 |

登录令牌只接受平台受众 `PLATFORM`。过期或无效令牌返回 401；权限不足返回 403。

| 方法 | 路径 | 权限 | 请求 | 成功 |

| GET | `/admins` | `platform.account.manage` | `page,pageSize` | 200 |
| POST | `/admins` | `platform.account.manage` | `username,displayName,password,roleCodes[]` | 201 |
| PATCH | `/admins/{publicId}/status` | `platform.account.manage` | `status` | 200 |
| POST | `/admins/{publicId}/roles` | `platform.account.manage` | `roleCodes[]` | 200 |
| GET | `/roles` | `platform.role.manage` | 无 | 200 |
| POST | `/roles` | `platform.role.manage` | `code,name,permissionCodes[]` | 201 |
| PUT | `/roles/{publicId}/permissions` | `platform.role.manage` | `permissionCodes[]` | 200 |

## 企业与实例

| 方法 | 路径 | 权限/签名 | 请求 | 成功 |
|---|---|---|---|---|
| GET | `/enterprises` | `platform.enterprise.view` | `page,pageSize,status?` | 200 |
| POST | `/enterprises` | `platform.enterprise.manage` | `name,contactName,contactPhone` | 201 |
| PATCH | `/enterprises/{publicId}/status` | `platform.enterprise.manage` | `status` | 200 |
| POST | `/enterprises/{publicId}/activation-codes` | `platform.license.manage` | `ttlHours,maxAttempts` | 201 |
| POST | `/instances/activate` | 无 | `activationCode,installationId,tenantDatabaseId,publicKeyPem,fingerprint` | 200 |
| GET | `/instances?enterpriseId=...` | `platform.license.view` | 查询参数 | 200 |
| POST | `/instances/heartbeat` | 实例 Ed25519 签名 | `licenseVersion,clientTime` | 200 |
| GET | `/instances/{publicId}/license` | 实例 Ed25519 签名 | 无 | 200 |
| POST | `/instances/{publicId}/ack-license` | 实例 Ed25519 签名 | `version` | 200 |

激活、心跳、授权拉取的签名请求需要 `X-Instance-Id`、`X-Instance-Timestamp`、`X-Instance-Nonce`、`X-Instance-Signature`。心跳接口不使用平台 JWT。

## 模块目录与套餐

| 方法 | 路径 | 权限 | 请求 | 成功 |
|---|---|---|---|---|
| GET | `/modules` | `platform.module.view` | `page,pageSize,status?` | 200 |
| GET | `/modules/{code}` | `platform.module.view` | 无 | 200 |
| POST | `/modules` | `platform.module.manage` | 模块基本信息 | 201 |
| PUT | `/modules/{code}/status` | `platform.module.manage` | `status` | 200 |
| POST | `/modules/{code}/versions` | `platform.module.manage` | `version,minCoreVersion` | 201 |
| PUT | `/modules/{code}/dependencies` | `platform.module.manage` | 依赖数组 | 200 |
| PUT | `/modules/{code}/prices` | `platform.module.manage` | 价格方案数组 | 200 |
| GET | `/plans` | `platform.plan.view` | 无 | 200 |
| POST | `/plans` | `platform.plan.manage` | 套餐及模块明细 | 201 |

依赖必须是 `FORMAL` 或 `PLATFORM_GRANT` 授权，试用授权不能满足依赖；循环依赖和菜单顺序冲突返回 422/409。

## 销售订单与授权

| 方法 | 路径 | 权限 | 请求 | 成功 |
|---|---|---|---|---|
| POST | `/orders/quote` | `platform.order.view` | 企业、套餐或模块购买项 | 200 |
| POST | `/orders` | `platform.order.manage` | 同报价请求 | 201 |
| GET | `/orders/{publicId}` | `platform.order.view` | 无 | 200 |
| POST | `/orders/{publicId}/pay-simulated` | `platform.order.manage` | `channel,channelTransactionNo` | 200 |
| POST | `/orders/{publicId}/retry-fulfillment` | `platform.order.manage` | 无 | 200 |
| POST | `/orders/{publicId}/refund` | `platform.order.manage` | `reason` | 200 |

创建订单必须带 `Idempotency-Key`。相同键和相同请求体返回首次结果；相同键对应不同请求体返回 `IDEMPOTENCY_CONFLICT`。支付、退款和履约重试按订单状态机校验，非法状态返回 409。

## 通用错误

所有错误均返回统一包络，`data=null`，并保留 `X-Trace-Id`。具体错误码见[平台控制面错误码](平台控制面错误码.md)。
