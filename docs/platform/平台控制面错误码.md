# 平台控制面错误码

| HTTP | 错误码 | 含义 |
|---:|---|---|
| 400 | `INVALID_REQUEST` | JSON、参数或请求体无效 |
| 401 | `UNAUTHORIZED` | 未登录或账号不可用 |
| 401 | `TOKEN_INVALID` / `TOKEN_EXPIRED` | 平台令牌无效或过期 |
| 403 | `PERMISSION_DENIED` | 平台账号没有所需权限 |
| 403 | `INSTANCE_SIGNATURE_INVALID` | 实例签名或实例目标不匹配 |
| 403 | `LICENSE_SIGNATURE_INVALID` | 授权文件签名无效 |
| 404 | `INSTANCE_NOT_FOUND` / `LICENSE_NOT_FOUND` | 实例或授权不存在 |
| 409 | `ACTIVATION_CODE_USED` | 激活码已被使用 |
| 409 | `ORDER_STATE_CONFLICT` | 订单状态不允许当前操作 |
| 409 | `IDEMPOTENCY_CONFLICT` | 幂等键对应了不同请求 |
| 409 | `MENU_ORDER_CONFLICT` | 在售模块菜单顺序冲突 |
| 422 | `MODULE_DEPENDENCY_MISSING` | 缺少正式依赖模块 |
| 422 | `MODULE_DEPENDENCY_CYCLE` | 模块依赖形成环 |
| 422 | `MODULE_ALREADY_PERPETUAL` | 已有永久授权，不能重复购买 |
| 422 | `PLAN_ALREADY_OWNED` | 套餐内模块均已有正式授权 |
| 500 | `INTERNAL_ERROR` | 未知服务端错误，响应不暴露堆栈或内部消息 |

错误响应结构：

```json
{
  "code": "ORDER_STATE_CONFLICT",
  "message": "订单状态不允许该操作",
  "data": null,
  "traceId": "tr_example",
  "timestamp": "2026-10-30T12:00:00Z"
}
```
