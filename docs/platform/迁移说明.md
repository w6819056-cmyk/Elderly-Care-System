# 平台控制库迁移说明

平台控制库只保存平台账号、企业授权关系、模块目录、销售订单、许可证、心跳和审计数据，不保存企业客户、员工、业务订单、支付业务流水或健康数据。

Flyway 迁移位置：`platform-core/src/main/resources/db/migration/platform`，运行时路径为 `classpath:db/migration/platform`。表统一使用 `pf_` 前缀。

生产部署采用只追加迁移策略：禁止修改已经执行的 `V1__*`、`V2__*` 文件；新增结构必须使用递增版本号。执行前备份平台控制库，并在预生产空库和已有数据副本上验证。

```powershell
mvn -f backend/pom.xml -pl apps/platform-app -am test
mvn -f backend/pom.xml -pl apps/platform-app -am package -DskipTests
java -jar backend/apps/platform-app/target/platform-app-2.0.0-SNAPSHOT.jar
```

H2 测试库由 `application-test.yml` 提供。MySQL 8 通过 `PLATFORM_DB_URL`、`PLATFORM_DB_USERNAME`、`PLATFORM_DB_PASSWORD` 配置。生产环境不得使用会 DROP 重建业务表的 `dev` profile，也不得把平台私钥写进仓库。
