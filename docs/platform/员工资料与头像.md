# 员工资料与头像

新建员工支持可选 phone、email、avatarDataUrl。email 最长 254 字符并校验邮箱格式；头像只接受 PNG/JPEG data URL，源文件不超过 2MB，最大边长 4096，解码后中心裁为 256px PNG。服务端不采信文件名或 MIME 声明。

V4 迁移在 iam_staff 增加 email、avatar_key，原有 phone 保持不变。新建表单与员工列表详情均读取实际字段，未填写显示“未填写”。

头像文件位于 app.staff-avatar-directory（默认工作目录 data/staff-avatars），部署可通过 APP_STAFF_AVATAR_DIRECTORY 指定企业持久化目录。请将目录与数据库共同备份，不要存放在临时目录或静态公网目录。

GET /api/tenant/v1/hq/staff/{publicId}/avatar 返回 PNG；必须持有员工查看权限且目标在本员工数据范围内，否则不返回文件。头像不使用公共静态 URL。客户端携带租户令牌读取 Blob，组件卸载后释放 Object URL。响应禁止缓存。

当前新增头像随新建员工提交；已有员工的资料编辑、替换头像另行接入，未伪装为已支持。
