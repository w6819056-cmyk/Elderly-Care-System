# 会员等级模块 1.0.0

## 交付形式与兼容性

源码位于 backend/modules/membership/membership-impl，前端、独立 SQL 和 manifest 同目录维护。模块为 thin JAR，不再作为 tenant-app 的固定依赖；以 membership-1.0.0.caremod 上传平台模块中心，通过企业安装中心交付。

最低底座运行协议版本为 2.1.0（需要 CustomerQueryApi、StaffAccessApi、总部动态页及消费者资料桥），最高不含 3.0.0。Maven 2.0.0-SNAPSHOT 是当前仓库开发坐标，不作为运行协议版本判断。升级宿主后，执行器配置的 coreVersion 也需改为 2.1.0。

## 功能

- 总部：创建/修改/停用会员等级，维护名称、排序、权益说明；搜索已注册消费者，开通会员、调整等级，查看含操作人、原因和时间的流水。
- 门店：消费者主动出示个人中心的客户编号后，查询最小会员卡。不提供门店客户全集、总部会员搜索或其他门店消费资料。
- 消费者：个人中心查看本人的等级与权益说明，显示客户编号供主动出示。普通注册不自动成为会员。

停用等级保留已有会员及说明，卡片显示“等级已停用”；禁止再分配该等级。权益仅为说明，不执行积分、折扣、储值或权益核销。相同客户只能有一份企业会员档案，跨企业不共享。

## 安装与开通

1. 平台创建 membership 模块目录并收录签名包，审核后发布。
2. 企业具备有效模块授权及激活实例，下载生成计划，由总部确认。
3. 已正确配置的执行器备份、迁移、重启并验证成功后，计划才显示已安装。
4. 总部启用模块、分配门店名额；在角色/权限组中选择会员模块权限并分配员工。
5. 总部菜单为 /modules/membership/manage，门店为 /modules/membership；均由服务器菜单与权限控制，不直接开放给任意账号。

未安装时不能仅输入上述 URL 使用功能。当前预览企业未完成激活及执行器配置，因此交付包已就绪不代表预览企业已经可以使用。

## 权限

| 权限 | 用途 |
|---|---|
| membership:level:read | 查看会员等级（总部） |
| membership:level:write | 新增、修改、停用等级（总部） |
| membership:member:read | 搜索客户、查看会员（总部） |
| membership:member:write | 开通会员、调整等级（总部） |
| membership:history:read | 查看变更流水（总部） |
| membership:identity:read | 查询客户主动出示的会员身份（门店） |

安装不自动给所有员工授权。门店即使误分配总部操作权限，业务接口仍检查总部身份；用户资料查询由宿主传入已登录客户编号，前端不能指定其他客户。

## 数据与接口

模块独立迁移 V1__membership.sql，新增 mem_level、mem_member、mem_change，不修改基础客户表。所有基础客户摘要通过 CustomerQueryApi 获取。等级采用版本校验，开通/改级和流水同事务，会员变更使用行锁。无删除等级接口。

接口前缀 /api/tenant/v1/modules/membership：levels、customers、members、members/{id}/level、members/{id}/history、lookup。消费者由宿主 /api/public/customer/features 返回本人模块卡，不能调用总部接口。

## 构建

```powershell
mvn -f backend/pom.xml -pl modules/membership/membership-impl -am package
New-Item -ItemType Directory -Force backend/modules/membership/membership-impl/payload/backend
Copy-Item backend/modules/membership/membership-impl/target/membership-impl-2.0.0-SNAPSHOT.jar backend/modules/membership/membership-impl/payload/backend/module.jar
node scripts/build-module-package.mjs backend/modules/membership/membership-impl/payload backend/modules/membership/membership-impl/manifest-template.json C:/private/development-private.pem C:/release/membership-1.0.0.caremod
```

正式发布须把模板 keyId 换成对应的可信发布者，私钥保存在仓库外，包发布后不可覆盖同版本。测试包使用独立预览发布密钥，正式客户不得复用。

## 验证

服务测试覆盖开通、改级、乐观冲突、同客户重复入会、并发改级只落一条流水、停用等级及门店管理拒绝。宿主测试验证消费者只查询自身、前缀客户搜索及模块错误 HTTP 状态。签名包冒烟测试在隔离 H2 中解包真实 JAR、执行模块 SQL、注册 Spring 配置，再通过 HTTP 接口验证业务和门店越权拒绝；不操作预览企业数据。
