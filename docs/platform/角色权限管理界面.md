# 角色与权限组管理

企业端 /hq/permissions 提供角色与权限组卡片、搜索、新建及配置侧栏。菜单按 iam.role.view / iam.permission-group.view 展示，写入按对应 manage 权限控制，API 仍为最终授权边界。

新增只读接口：GET /api/tenant/v1/hq/roles/{publicId} 返回 role、permissionGroupCodes、permissionEffects；GET /api/tenant/v1/hq/permission-groups/{publicId} 返回 group、permissionCodes。分别要求对应 view 权限。

编辑前先加载完整配置，失败禁止保存，防止空集合覆盖旧权限。已创建的编码、名称及角色域在本轮只读，现有更新接口仅替换权限配置。单独 DENY 优先。TENANT_OWNER 与 TENANT_OWNER_ALL 仅查看；服务端原有保护继续生效。

员工卡片现支持角色分配编辑及总部员工门店范围配置。GET /api/tenant/v1/hq/staff/{publicId}/access 返回 roleCodes、protectedOwner、scopeType、storePublicIds、storeGroupPublicIds；要求 iam.staff.view 且目标在当前数据范围内。

前端先读取当前绑定，角色全量替换使用现有 PATCH roles；范围使用现有 PUT data-scope。保存前确认影响。范围配置仅 ALL 范围管理员可写，总部支持 SELF/ALL/STORES；已配置 STORE_GROUP 可保持不变，门店组创建和成员维护尚未接入本界面。门店员工固定所属门店；所有者受保护。
