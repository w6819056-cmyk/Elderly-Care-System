# 模块售卖界面

平台模块售卖入口：`/module-shop`。独立套餐管理入口：`/plans`。

模块售卖分出售预览和模块编辑。卡片绑定已有模块，一模块一卡片，图片支持 HTTPS 地址或本站 /images/ 路径。保存的是数据库字段。只有卡片开启且模块 ON_SALE 才显示。价格、期限、门店额度、上下架仍使用原商品接口。会员封面默认使用 /images/membership-cover.svg。

迁移：V7__module_storefront.sql，仅新增字段。新增模块先在模块中心登记，再到模块编辑创建售卖卡片和价格。

出售预览用于平台审核商品，不创建企业订单。企业总部自助购买接口仍待接入；现阶段创建授权订单使用原销售授权页面。
