# 门店咨询与参观预约

公开页面 /stores/:storeNo/visit 收集称呼、电话、预约类型（咨询/参观）、意向日期、备注。不要求用户账号，不收款、不承诺锁定时间。门店联系确认后再将状态改为已确认。

独立 V6 迁移创建 core_visit_booking，注册 core.visit.view / core.visit.manage，并加入受保护所有者权限组。普通总部/门店角色需在角色管理显式授予，不能自动扩大员工已有权限。

POST /api/public/store-portals/{no}/visit-bookings 仅接受营业门店，日期限上海时区今天起 90 天内。服务进程按连接 IP 限流；多节点部署需网关统一限流。返回编号，不公开访客列表或无身份查询。

GET /api/tenant/v1/visit-bookings 需要 core.visit.view。PATCH /.../{id}/status 需要 core.visit.manage，二次校验门店范围及营业状态，行锁下更新并审计。门店员工范围固定所属门店。

状态：PENDING → CONFIRMED/CANCELLED；CONFIRMED → COMPLETED/CANCELLED；终态不可反转。总部 /hq/visits，门店 /store/visits。不包含实际付费服务预约、排班名额、支付、短信和自动改期。

头像/联系资料与预约都留在企业系统，平台控制面不采集访客信息。预约数据保留和删除管理后续补充，不自动删除。
