## 当前实现边界

- 平台控制库使用 `pf_` 表，只保存平台控制面数据，不保存企业客户、员工、健康和业务订单数据。
- 平台 JWT 与实例 Ed25519 签名分离；实例断网期间由租户本地授权缓存继续运行，联网后由心跳刷新。
- 实例激活、Ed25519 签名心跳、授权拉取/确认由 `EnterpriseActivationIntegrationTest` 和 `HeartbeatLicenseIntegrationTest` 覆盖；销售冒烟脚本不自行生成实例密钥或签名请求。
- 平台异常统一返回 `ApiResponse`，未知异常不返回堆栈或内部错误消息。
- 平台 API、错误码和迁移策略见 `docs/platform/`。

## 部署注意事项

- 生产环境必须通过环境变量提供 JWT 密钥和许可证私钥，不能使用测试配置。
- 当前冒烟使用本机 `root` 测试账号和专用 `elder_care_platform` 库；生产环境应创建最小权限数据库账号并单独保管密钥。
