## 4. 本次发现并修复的问题

1. **测试 SQL 编码不稳定**
   - 现象：Windows 默认平台编码为 GBK，合法 UTF-8 的 `data-demo.sql` 在测试初始化时被错误解码。
   - 修复：在 `backend/apps/tenant-app/src/test/resources/application-test.yml` 指定 `spring.sql.init.encoding: UTF-8`。
   - 结果：原租户测试恢复 22/22 通过。

2. **架构测试缺少应用模块版本治理**
   - 现象：`architecture-tests` 引用 `platform-app` 和 `tenant-app` 时，父 POM 未在 `dependencyManagement` 中声明版本。
   - 修复：在 `backend/pom.xml` 增加两个应用模块的版本管理。
   - 结果：架构测试 3/3 通过。

3. **PowerShell 统一脚本误判成功状态**
   - 现象：子脚本成功时，`$LASTEXITCODE` 仍可能保留上一项 Maven 的非零值。
   - 修复：结构检查失败改为抛出异常；调用脚本不再依赖残留的 `$LASTEXITCODE`。
   - 结果：`verify-all.ps1` 完整通过。
