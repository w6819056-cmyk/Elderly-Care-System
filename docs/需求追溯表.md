## 非功能需求

| 编号 | 要求 | 当前情况 | 说明 |
| --- | --- | --- | --- |
| 4.1 性能 | 页面响应 ≤ 2s（P95） | 单机实测未压测 | 需压测环境验证；已建关键索引 |
| 4.1 性能 | 商城列表 500 并发 | 未压测 | 建议后续用 JMeter/wrk 验证 |
| 4.1 性能 | 告警推送 ≤ 10s | 同步推送，通常毫秒级 | 引入真实短信网关后受第三方时延影响 |
| 4.1 性能 | 单日消息 10 万条 | 未压测 | 消息入库为单条 insert，量大需改批量/MQ |
| 4.1 性能 | 可用性 ≥ 99.5% | 单实例部署 | 需多实例 + 负载均衡 |
| 4.1 性能 | RPO ≤ 24h | 依赖 MySQL 备份策略 | 未在代码层实现，需运维配置 |
| 4.2 安全 | 鉴权与最小权限 | 已实现 | JWT + 角色 + 数据归属校验；越权测试全覆盖 |
| 4.2 安全 | 密码存储 | 已实现 | BCrypt 哈希，接口不返回密码字段 |
| 4.2 安全 | 传输加密 | 未实现 | 生产需启用 HTTPS |
| 4.3 适老化 | 大字模式、高对比度 | 已实现 | 小程序首页开关，本地持久化 |
| 4.3 适老化 | 语音播报（ACC-02） | 未实现 | 可接入微信同声传译插件 |
| 4.4 兼容性 | 浏览器/机型 | 部分验证 | 管理端为现代浏览器；小程序需真机回归 |
| 4.5 数据管理 | 实体与备份 | 实体已建 15 张表 | 备份策略需运维配置 |
| 4.6 隐私合规 | 最小必要、脱敏、授权 | 部分 | 授权校验已实现；日志脱敏与导出审计未实现 |

## 未实现项汇总（需在答辩或验收时说明）

1. 社区生活模块（CM-01~CM-06）、视频探望（FM-02/FM-07）、投诉处理（OP-05）——文档中为二期或占位。
2. 定时类功能：用药到点提醒、慢病随访、久未活动判定、健康周报/月报——需要调度组件。
3. 第三方对接：真实微信支付、短信网关、微信订阅消息、对象存储、音视频 SDK、MQTT 设备——代码中均留有扩展点，一期使用模拟实现。
4. 免打扰（MSG-04）、紧急联系人通知顺序（SA-10）、体检报告归档（HC-10）。
5. 非功能项中的压测、HTTPS、多实例部署、备份策略需在部署阶段补齐。
