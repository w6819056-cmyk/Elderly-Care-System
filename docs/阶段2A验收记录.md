## 核心安全验证

- 租户员工令牌 audience 为 `TENANT_STAFF`；旧业务令牌不能进入租户 v1 路由。
- 每个请求从租户库重新加载员工状态、角色、权限和数据范围；停用员工立即失去已有令牌访问能力。
- 权限代码必须已由程序注册；角色域必须和员工域一致；`DENY` 覆盖授权并集；受保护所有者不可被普通权限操作修改。
- STORE 员工的范围固定为绑定门店；总部员工可设为 `ALL`、`STORES`、`STORE_GROUP` 或 `SELF`；门店组变化会被已有令牌的下一次请求实时解析。
- 门店生命周期采用白名单流转与版本比较；企业资料、门店、员工和 IAM 变更记录租户审计。
- 新迁移只追加 Flyway 文件，不依赖会 DROP 的演示 schema；平台控制库仍不接触企业员工或客户信息。
