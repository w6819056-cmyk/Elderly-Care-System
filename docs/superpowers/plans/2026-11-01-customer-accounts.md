# 用户注册登录与预约持久查询

用户确认接入消费者账号、个人中心和我的预约。根因：原预约已写入数据库，但回执编号仅存 React state，刷新丢失显示。

实现步骤：V9 新增独立 customer_account/customer_session，预约添加可空 customer_id；消费者接口独立于员工认证；注册 BCrypt 密码、随机令牌摘要存储、七天过期、退出撤销；认证接口按 IP 和账号限流。前端在预约前要求登录，提交后链接个人中心，列表仅从数据库查询当前账号的预约。公开页面添加用户入口，保持后台入口分离。历史匿名预约不凭手机号自动认领。

账号为企业数据库内跨门店身份，不向平台总部同步。第一版账号密码，手机号仅预约联系方式，不表示已验证；短信登录、找回密码、会员权益本轮未接入。令牌存浏览器独立 customer 命名空间，不使用员工令牌。

验证：注册登录、刷新后重新查询、用户间隔离、无令牌访问拒绝、退出后旧令牌失效、员工认证互不通用；前端构建、测试；保持既有预约后台操作正常。
