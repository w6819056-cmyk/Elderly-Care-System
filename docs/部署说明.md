# 部署说明

## 环境要求

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 17 | 打包编译使用；本机已装 `C:\Program Files\Java\jdk-17` |
| Maven | 3.8.1 | 本机已装 `E:\apache-maven-3.8.1` |

## 一、数据库准备

宝塔面板中 MySQL 默认 `root` 密码需要确认，或新建专用账号：

```sql
CREATE DATABASE IF NOT EXISTS elderly_care
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

CREATE USER IF NOT EXISTS 'elderly'@'localhost' IDENTIFIED BY 'Elderly@2026';
GRANT ALL PRIVILEGES ON elderly_care.* TO 'elderly'@'localhost';
FLUSH PRIVILEGES;
```

对应的 `application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/elderly_care?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: elderly
    password: Elderly@2026
```

## 二、后端

```bat
cd /d E:\yanglao\backend
mvn clean package -DskipTests
java -jar target\elderly-care-backend-1.0.0.jar --spring.profiles.active=dev
```

或直接开发模式：

```bat
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

说明：

- `dev` profile 会在启动时执行 `db/schema.sql` 与 `db/data-demo.sql`，**会先 DROP 再建表**，勿在生产使用。
- 生产启动去掉 profile，改为手工执行脚本，并设置环境变量：

```bat
set APP_JWT_SECRET=<32字节以上的随机串>
java -jar target\elderly-care-backend-1.0.0.jar
```

- 验证：访问 http://localhost:8080/swagger-ui.html 能看到接口列表。

## 三、管理端

开发：

```bat
cd /d E:\yanglao\admin
npm install --registry=https://registry.npmmirror.com
npm run dev
```

生产构建：

```bat
npm run build
```

产物在 `admin/dist/`，用 Nginx 托管并反向代理 `/api` 到后端：

```nginx
server {
    listen 80;
    server_name _;

    root /path/to/admin/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 四、小程序

1. 微信开发者工具 → 导入项目 → 目录选 `E:\yanglao\miniprogram`。
2. AppID 填自己的或选"测试号"（`project.config.json` 里当前为 `touristappid`）。
3. 详情 → 本地设置 → 勾选"不校验合法域名…"。
4. 后端地址在 `app.js` 的 `globalData.baseUrl`，开发者工具用 `http://localhost:8080`，真机调试改成电脑局域网 IP（如 `http://192.168.1.10:8080`），并确保手机与电脑同一网段、防火墙放行 8080。

正式发布前需要：企业主体小程序、配置服务器域名白名单（HTTPS）、申请订阅消息模板。

## 五、Docker 部署（可选）

需先启动 Docker Desktop，随后在项目根目录执行：

```bash
docker compose up -d --build
```

（`docker-compose.yml` 未包含在本次交付中，如需容器化部署可再补。当前推荐用上面的 jar 直跑方式。）

## 六、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 后端启动报 `Access denied for user` | 数据库账号密码不符 | 改 `application.yml` 或用环境变量覆盖 |
| 启动报 `Table 'xxx' doesn't exist` | 未启用 dev profile 且未手工建表 | 执行 `schema.sql` 与 `data-demo.sql` |
| 管理端登录提示"登录失败" | 后端未启动或端口不符 | 检查 8080 与 Vite 代理配置 |
| 小程序请求失败 | 未勾选"不校验合法域名"或 baseUrl 非本机可访问 | 见上文第四条 |
| 小程序 401 后自动跳登录 | token 过期（72h） | 重新登录 |
| 演示数据被重置 | dev profile 每次启动重建表 | 属预期行为，改用非 dev profile 即可保留数据 |
